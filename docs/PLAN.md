### T1 · 右键可发现性

**目的**：补 D-025 留下的代价 —— 用户不知道能右键。

**改哪里**：`src/App.tsx`

**最小改动**

```
1. 读 3w:rightclick-hinted（localStorage，缺省 false）
2. 第一次成功发出消息后（handleSend 里 pendingSend 提交那一步之后）：
   · 如果还没提示过 → pushToast 一条
   · 写入 3w:rightclick-hinted = 1
3. 提示文案见下
```

**文案**（按项目调子：短、不哄人、说事实）

```
title: 右键
desc : 消息上可以复制、引用、朗读
```

**不做**：
- ❌ 不做常驻提示条（会变成永久噪音）
- ❌ 不做引导页改版（那是另一件事）
- ❌ 不动菜单项（D-024 刚定）

**怎么算过**
- [ ] 全新数据下，发第一条消息 → 弹出一次
- [ ] 关掉重开 → **不再弹**
- [ ] 第二次发消息 → 不弹
- [ ] 清掉 `3w:rightclick-hinted` → 又弹一次

## 十三 · 整体验证

每做完一个任务，走同一条链：

```
npx tsc --noEmit          → 必须零输出
npm run build             → 必须成功
run-electron --prod       → 起得来
CDP 查证 + 截图            → 肉眼可见（尤其是 UI 改动）
npm run pack              → 出新 exe
清理测试数据               → reload 让 React 重读，等 12 秒落盘，再核对文件
```

> **测试数据清理有个坑**（这几轮踩过两次）：直接改 localStorage 后立刻强杀，
> 改动不会落盘，重启后会"复活"。
> **必须 reload 让 React 重读，再等 12 秒。**
