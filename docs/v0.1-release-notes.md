这是《生境》第一次向深渊之外敞开大门。

## 这是什么

本地优先的多智能体社交客户端。

出厂时，这里只有一片深渊。你需要自己接入 AI、自己建立角色，也自己决定要让她们记住什么。
角色、对话和记忆都留在你自己的机器上，不上传。

## 装之前要知道

- **系统**：Windows 10 / 11（x64），安装包约 **90 MB**
- **必须自备**：一个 OpenAI 兼容的 API，包括 Base URL 和 Key
- **软件不内置任何模型，也不提供模型额度**
- **数据在哪**：`%APPDATA%\habitat\`
- **卸载**：卸载不会删数据。重装之后，原来的角色和对话还在

## 这一版有什么

- **遗忘机制**：记忆会随时间衰减。不同类型的记忆有不同的保留方式 ——
  这一版是四个固定档（短期 / 情绪 / 偏好 / 长期），提取次数够了会进更稳定的状态
- **记忆提取**：从对话里认出值得留下的句子，用本地规则，不额外调用模型
- **6 秒待发**：消息送出去之前有 6 秒可以撤回。**这 6 秒里她收不到任何东西**
- **界面和声音**：四栏深海界面、代码合成音效、基础语音
- **危险操作确认**：删档要手打「删档」两个字

## 已知问题

- **出厂模型名不一定被你的中转服务支持**：会报「模型不存在」或「没有可用渠道」。
  用控制台命令改：

  ```
  ai model <角色> <模型>
  ```

- **平台**：只提供 Windows 打包版。macOS / Linux 的跨平台代码在，
  但没有真正打包跑过
- **接口差异**：不同服务对 OpenAI 兼容接口的支持程度不一样，部分需要手动调模型名或 Base URL
- **声音**：走系统 TTS，不同系统的音色差别很大

## 升级注意

v0.1.0 是第一个版本，没有「从旧版升上来」这回事。

但从这一版起记住一件事：**没有自动备份。** 换机器、换安装位置之前，自己复制一份：

```
%APPDATA%\habitat\
```
