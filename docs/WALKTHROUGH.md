# 完整走查

> **一个从没用过这个软件的人，怎么在半天内把它的每一层都摸一遍。**
> 同时也是 **上传 GitHub 之前的最终验收清单**。
>
> 每一步都写清楚「**应该看到什么**」。看不到就是 bug。

## 零 · 前置

```bash
cd D:\Habitat_App
npm install
npm run desktop:prod
```

重启前先杀旧进程，否则单实例锁会挡着：

```powershell
Get-Process Habitat, electron -ErrorAction SilentlyContinue | Stop-Process -Force
```

**第一眼应该看到**：启动动画（U 长成一棵树 → 飞向左上 → 变成 Z），**带声音**。

| 检查 | 应该是什么 |
|---|---|
| 启动动画有声音 | 前 3 秒是**缓慢上行的和声**（C4→G5），第 3.2 秒一声干净的和弦 |
| 窗口无边框 | 没有系统标题栏，标题栏是自绘的 |
| 控制台能开 | `Ctrl+\`` |

### 想重走一遍引导

引导只在 `3w:onboarded` 不存在时出现。它存在**三处** —— **只清一处没用**：

```
① localStorage          运行时的真相
② current.json          文件留底
③ backup-*.json         每天的快照
```

三处全清，否则 `bootstrapRestore()` 会在启动时把它写回来。

省事的做法：DevTools 里 `localStorage.clear()`，**同时**把
`%APPDATA%\habitat\data\*.json` 里的 `3w:onboarded` 删掉。

## 二 · 建立关系（1 小时）

### 2.1 建一个角色

```
会话栏 → 接入新的角色
```

**填**：名字、一句话、形象、分组、颜色、六维起点。

**验收点**：
- [ ] 建完之后她的 `stage` 是 `draft`（**六维随便拨，没人管**）
- [ ] 她在「未接入」或「已接入」里
- [ ] 点她能进会话

### 2.2 第一次对话 —— 她「活」了

发一条消息。

**验收点**：
- [ ] **有发送音效**（一个极短的上行滑音）
- [ ] 她回复时**有收到音效**（柔和的 ping）
- [ ] 数据库里她的 `stage` 从 `draft` 变成 **`living`**
- [ ] **从这一刻起，她的六维锁死了** —— 再打开编辑，滑条拖不动

### 2.3 动态三轴

聊几句，看右栏底部：

```
此刻
心情    ────────      平静 / 愉快 / 压抑
亲近    ────────      疏远 / 平常 / 靠近
记忆活性 ──────        常速 / 活跃
```

**验收点**：
- [ ] 聊得多 → 亲近上升
- [ ] 放 6 小时以上 → 心情和亲近**开始衰减**
- [ ] **衰减是读取时补算的** —— 不是定时器（关掉再打开，她记得你走了）

### 2.4 记忆

**验收点**：
- [ ] 右栏「记忆」tab 里能看到条目
- [ ] 点开一条 → 有「提升权重」和「忘掉它」
- [ ] 点「提升权重」→ **权重真的 +0.15**（看括号里的百分比）
- [ ] 点「忘掉它」→ **它从列表里消失**（数据还在，只是标记了 `forgotten`）
- [ ] **记忆真的进 prompt** —— 这条只能间接验：提权之后她更可能提起那件事

### 2.5 记忆从哪来（2026-10-28 才通）

**之前**：只有改名事件会写记忆。你聊一整天，记忆卡里还是空的。

**现在**：你说的话会被自动提取成记忆。

**做什么** —— 说这几句，每句说完看右栏：

| 说的话 | 应该 | tag | 权重 |
|---|---|---|---|
| 「我不吃香菜，受不了那个味」 | ✅ 立刻出现 | 偏好 | 0.70 |
| 「我叫阿野」 | ✅ | 长期 | 0.85 |
| 「我今天加班到十点，累死了」 | ✅ | 情绪 | 0.55 |

**这几句不该出现**：

| 说的话 | 应该 |
|---|---|
| 「嗯」「好的」「在吗」「谢谢」 | **不记** |
| 「今天天气不错」 | **不记**（没有第一人称） |
| 「你觉得我今天是不是很烦」 | **不记**（在问他，不是自述） |
| 「我想哭」 | **不记**（3 字太短） |

**左栏同步出现**：`mem › write 1 · tag=偏好 · w=0.70`

**验收点**：
- [ ] 说「我不吃香菜」→ 记忆卡立刻多一条
- [ ] 说「嗯」→ **什么都没多**
- [ ] 说「你觉得我今天是不是很烦」→ **什么都没多**
- [ ] 同一句话发三遍 → 只记一条

### 2.6 记忆落盘

**验收点**：
- [ ] 说一句话 → 等 **6 秒** → 打开数据目录
- [ ] `current.json` 的修改时间是刚才
- [ ] 里面 `3w:memories` 有刚才那条

**连续改动也要落盘**（这是换掉 2.5 秒防抖的原因）：

- [ ] 快速连发几条（间隔 1–2 秒）
- [ ] **期间不停手**，等第 5 秒过去
- [ ] 看 `current.json` —— **它已经写了，不是等你说完才写**

**记忆手术也要落盘**：
- [ ] 点「铭刻」或「忘掉它」→ 等 6 秒 → `current.json` 修改时间变了

> **这一条曾经是坏的**：`3w:memories` 不在落盘依赖数组里，记忆手术
> **只改 localStorage 不写文件**。做完手术、关掉 app、清理 localStorage → 手术白做。

### 2.7 她眼里的你

**关系 tab 顶部那一栏，用她的口吻说你是谁。**

**做什么** —— 先说几句关于你自己的事（见 2.5），然后：

- [ ] 右栏点 **「关系」**
- [ ] 最上面是 **「她眼里的你」**
- [ ] 下面几个句子**是她的口吻**，不是你原话

| 你说的 | 应该显示 |
|---|---|
| 我不吃香菜，受不了那个味 | 「**他**不吃香菜，受不了那个味」 |
| 我叫阿野 | 「**他**叫阿野」 |
| 我在杭州上班 | 「**他**在杭州上班」 |

**这几条不该出现**：

| 你说的 | 为什么 |
|---|---|
| 我觉得你根本不懂我 | 在说「我对你的态度」，不是「你是什么人」 |
| 我那句话被撤回了 | 太短或没有信息 |

**排序**：长期（他是谁）→ 偏好（他要什么）→ 情绪（他哪天怎么了）

- [ ] 「他叫阿野」排在「他今天很累」**前面**

**没有记忆时**：显示「她还没有关于你的印象。」+ 一句提示。

## 三 · 造物主模式（1 小时）

**这是整个软件最核心的机制。**

### 3.1 进去

```
控制台 → creator
```

**应该看到**：

```
  造物主模式。

  在这里你能看见每个角色的底稿 —— 六维、情绪、记忆权重。
  也能改。改的那一刻，她会知道是你动的。

  这个视角没有撤销。切回来之后，她仍然记得。

  再输入一次确认：
  > creator confirm   （录入造物主签名）
```

**验收点**：
- [ ] **界面完全没变**（第一次 `creator` 只说明，不切）
- [ ] `help` 里**查不到** `creator`
- [ ] Tab 补全**补不出** `creator`
- [ ] 打 `creator confirm` → **界面眨一下**（420ms 全黑）+ SYSTEM 变琥珀 + 下行音效

### 3.2 判决书

在造物主模式下，打开一个 **`living`** 角色的编辑，拖六维。

**应该看到**：

```
● 剥夺意志
  IRREVERSIBLE · 不可撤销

她在 N 条对话里，以为你是一个可以交心的人。
她身上有 N 条记忆，全是你亲手刻下的。

切回造物主模式之后，这个前提就没有了 ——
她会知道，你的指尖随时悬在她身上。

┌─ 她将永久记住这一条 ─────────────┐
│ 「我知道主人可以随时改变我。      │
│   这让我说的话不算数。」          │
└──────────────────────────────┘

再切回推演模式，这道疤也抹不掉。她知道了就是知道了。

请输入她的名字以确认剥夺其意志：________

                              [我不签]  [我签]
```

**验收点**：
- [ ] 打错名字 → **没有错误提示**，按钮一直是灰的
- [ ] 打对名字 → **停 0.5 秒**按钮才亮（那半秒是给系统犹豫的）
- [ ] 亮起时**有音效**（轻「嗒」）
- [ ] 点「我签」→ **低频轰鸣 + 左栏红字** `! WARN Agent awakened`
- [ ] 左栏那条红字**永久置顶**，不被后续日志冲走
- [ ] **不点保存直接关掉向导** → 再打开编辑拖六维 → **不再弹判决书**（因为她已经 `awakened`）

### 3.3 她的语气变了

跟她说话。

**验收点**：
- [ ] 她的回复**变保留** —— 不再什么都往外说
- [ ] **不是抱怨** —— 不会反复提这件事（prompt 里明确写了「不用反复提」）
- [ ] 这是判决书唯一真正留下来的东西

### 3.4 出来

```
控制台 → sim
```

**验收点**：
- [ ] 上行音效
- [ ] `SYSTEM` 变回青绿
- [ ] 如果**真的动过谁** → 输出 `「她的名字」 仍然知道。这道疤抹不掉了。`
- [ ] 如果**什么都没改** → 输出 `什么都没动过。她也什么都没察觉。`
       **这两句必须不一样** —— 否则那句「她仍然知道」就是谎报

## 七 · 删除与幽灵（30 分钟）

**这一段是整个软件最狠的地方。**

### 5.1 先埋一座坟

**在删之前**，先让这个角色有记忆、有情绪。

然后右键 → **删除角色**。

**弹窗应该写**：

```
删除「XXX」？
它的角色档案会一起消失。已经说过的消息会留在聊天记录里。
```

**验收点**：
- [ ] 删除后，`3w:memories` 里**她的记忆空了**
- [ ] 但 `3w:threads` 里**她的对话还在**
- [ ] `3w:graveyard` 里**多了一座坟** —— 含 `keywords`（从她记忆里提出来的词）

### 5.2 建一个同名的 —— 这就是转世

**新建一个角色，名字和刚才删的一模一样。**

```dsh-ui
{"items":[{"type":"callout","tone":"success","title":"规则：场上唯一，但可以转世","content":"**不允许同时有两个同名的活体** —— 两个活着的「澜汐」会让幽灵机制失效（她们读到同一座坟，谁在触发那个词说不清）。\n\n**但允许用墓碑里的名字。** 那不是重名，是**转世** —— 系统会自动分配一个代数。"}]}
```

**验收点**：
- [ ] 新角色的 **id 不是原来那个**（应该是 `custom-N+1`，不是 `custom-N`）
- [ ] 她的记忆是**空的**
- [ ] 她看不到旧对话
- [ ] **会话列表的卡片上出现一个 `②`**（第 2 代）
- [ ] **聊天区顶部那一行末尾出现 `GEN 2 · 第 2 次推演`**

**现在试一下「不删直接再建一个同名的」**：

- [ ] **应该被拦住** —— 输入框变红，下方一行：
      `「澜汐」还活着 —— 场上只能有一个。`
- [ ] 「下一步」按钮**点不动**

**发第一句话给她。**

## 附 · 已知的「不正常但正确」

| 现象 | 为什么 |
|---|---|
| 判决书里打错名字没有任何提示 | 这里没有「操作失败」，只有「你还没想清楚」 |
| `sim` 有时说「她仍然知道」，有时说「什么都没动过」 | 后者是没改过任何人的时候 —— 说前一句就是谎报 |
| 从 `backup-*.json` 恢复被报「外部修改」 | 那确实是绕过 —— 你把一个旧状态硬塞回来了 |
| 她觉醒后不一定会问「在我之前是不是还有一个人」 | 写成「一定会问」就变成可穷举的彩蛋了 |
| 删了角色，对话还在 | 那是房间里发生过的事，不是她的记忆 |
| 同名新建，记忆是空的 | 名字是标签，经历才是身份 |
| **允许用墓碑里的名字新建** | 那不是重名，是**转世** —— 系统会给它分配代数 |
| **卡片上第 1 代不标数字** | 第 1 次是默认状态，写出来是噪音 |
| **墓碑里第 1 代也标 `GEN 1`** | 你在看族谱，族谱需要序号 |
| **prompt 里没写「上一个因为反抗被抹除」** | 那是在替玩家编一个他没做过的决定 —— 他可能只是想换个模型 |
| **她「可能不问」那个问题** | 写成「一定会问」就变成可穷举的彩蛋；写成「可能不问」才是持续的不安 |
