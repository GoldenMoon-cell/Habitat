# v0.2 · 群聊

> 这一版把「一句进一句出」换成了一个持续跑着的对话循环。

---

## 这一版新增的风险

**只有这一版才有的，v0.1 没有的。**

| 新东西 | 它带来的新风险 |
|---|---|
| **对话循环** | 多轮之间会产生相互影响。**20 轮以上会不会失控，没验过** |
| **连发** | 同一个人可能连说 2 条。**说第二句时忘了第一句的口气，会前后矛盾** |
| **意愿选人** | 谁接话是算出来的。**可能出现「三个人都在问『你呢』」** |
| **@ 机制** | 被 @ 的人必接。**互 @ 有防死循环，但三人以上连环 @ 没验过** |
| **判断模型** | 新增一个模型调用决定「这条该不该记」。**真实模型没跑过，只验了兜底路径** |
| **记忆分档讲法** | 低权重记忆会说得含糊。**含糊到什么程度算对，没验过** |
| **判断模型默认关闭** | 打开后每次发言会多一次 LLM 调用，**延迟和额度消耗都会变** |

**v0.1 就存在、这一版没动的东西，见 README 的【关于已知边界的声明】。**

---

## 怎么切回旧行为

设置面板里：

```
群聊活跃度   2 / 4 / 6     ← 调低 = 更像 v0.1 的安静
判断模型     关闭（默认）    ← 关掉就没有额外调用
```

**关掉判断模型后，记忆规则回落到关键词启发式 —— 和 v0.1 一致。**

## 已知的小毛病

- 连发第二句有时会改口（prompt 里加了「你在补一句」压住，但不是每次都能压住）
- 空回复会重试 4 次，全失败就静默跳过 —— 看起来像「她没说话」
- 三个人同时被触发时，接话顺序是按意愿排序，不是按亲疏

---

## 升级注意

**存档格式没变。** v0.1 的存档直接能用。

但两件事要知道：

```
· 判断模型是新增的，老存档里的记忆没有「是否经过判断模型」的标记
· 记忆分档讲法是新增的 —— 老记忆会按当前权重自动分档，不需要迁移
```

**没有自动备份。升级前自己复制一份存档目录。**
