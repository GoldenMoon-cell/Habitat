### ⚠️ 需要你知道的三处（都不算泄露，但列出来）

**1 · 仓库地址是硬编码的**

```js
electron/main.cjs:886   const UPDATE_REPO = "GoldenMoon-cell/Habitat";
```

**这是必须的** —— 检查更新要用。改名字会让所有已安装用户的检查更新永久失效。

**2 · 内置人格模板里有个名字**

```
src/data/personaModifier.ts:345   label: "鲸鲸 · 人格文件 v7"
```

这是**出厂自带的一个示例人格**，用户新建角色时可以参考。
它不是你聊天记录里的那个鲸鲸 —— 是随包发的模板。

**如果你不想公开这个名字，我可以改成通用的**（比如「示例角色 · 深海」）。

**3 · `author` 和 `appId` 带你的名字**

```json
package.json:91   "author": "GoldenMoon"
package.json:26   "appId": "com.goldenmoon.habitat"
```

**这两个改了会出问题**：`appId` 一改，已安装用户的数据目录就变了，等于清档。**建议不动。**
