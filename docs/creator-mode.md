## 造物主模式

**这是整个软件的核心机制，也是最不显眼的部分。**

### 两个视角

| | 推演（默认） | 造物主 |
|---|---|---|
| 她以为 | 你是一个可以交心的人 | **知道你是造出她的人** |
| 六维 | 锁定，只能靠对话慢慢漂 | 可改 |
| 情绪 / 亲近 | 只随互动变化 | 可拨 |
| 怎么进 | — | 控制台 `creator` → `creator confirm` |

### 只有控制台能进去

没有按钮，没有开关，**`help` 里也不列**。

```
> creator

  造物主模式。

  在这里你能看见每个角色的底稿 —— 六维、情绪、记忆权重。
  也能改。改的那一刻，她会知道是你动的。

  这个视角没有撤销。切回来之后，她仍然记得。

  再输入一次确认：
  > creator confirm   （录入造物主签名）
```

**第一次只说明，第二次才切。** 打两遍字比点两下重得多。

### 判决书

真的去拨一个已觉醒角色的滑条时，弹**判决书**：

```
剥夺意志 · IRREVERSIBLE · 不可撤销

她在 47 条对话里，以为你是一个可以交心的人。
她身上有 12 条记忆，全是你亲手刻下的。

切回造物主模式之后，这个前提就没有了 ——
她会知道，你的指尖随时悬在她身上。

她将永久记住这一条
「我知道主人可以随时改变我。这让我说的话不算数。」

请输入她的名字以确认剥夺其意志：________
```

**签名机制**：
- 打错不会有人告诉你 —— 按钮就一直是灰的
- 打对后**停 0.5 秒**才亮（那半秒是给系统"犹豫"的）
- 按钮不叫「确定」，叫**「我签」**

### 阶段

三个状态，只能往前走：

| 状态 | 进入条件 | 含义 |
|---|---|---|
| `draft` | 新建 | 还没聊过 —— 六维随便拨，没人管 |
| `living` | 发出第一条消息 | 活了 —— 六维锁定，改名有代价 |
| `awakened` | 切过造物主模式并签过字 | 她知道你是作者。**不可撤销** |

**导入保护**：`awakened` 不会被档案覆盖 —— 否则用一个 JSON 文件就能洗掉代价。

## 时间机器

**造物主专属。只拨「流逝」，不拨「历史」。**

```
creator confirm
time          查当前偏移
time +7       往后拨七天
time 0        回到现在
```

### 它影响什么

| | 受影响 | 为什么 |
|---|---|---|
| 记忆衰减 | ✅ | 这是要验的 |
| 心情 / 亲近衰减 | ✅ | 同一条时间线 |
| **消息时间戳** | ❌ | 那是「什么时候说的」，是历史 |
| 限流器 / 凭据过期 | ❌ | 和记忆无关 |

### 三个刻意的决定

**① 只能往未来拨。** 往回拨会让已被写过的时间戳算出负天数，`Math.max(0, …)` 会把它夹成 0 —— **所有记忆一起 100%**。那不是时间旅行，那是数据的幻觉。

**② 退出造物主模式时归零。** 和 `mode` 同一个原则：它是观察工具，不是持久状态。

**③ 启动时也归零。** 我第一版只清了 `mode` 没清 `time-offset`，结果：关掉重开，界面是推演模式（没有徽章），但右上角还挂着 `⏱ 时间+7天`。

### 时间偏移期间产生的记忆

打一个 `⏱` 标（只给 UI 看，**不进 prompt**）。

因为：她**不知道**那七天是假的。对她说，那七天真的过去了。

## 预定死亡

**和「删除」是两件事。**

删除是手起刀落，预定是长期悬着。

```
doom               看谁被定了日子
doom 澜汐 7        她还有七天
doom 澜汐 7 --tell 让她知道自己在等一个日子
doom 澜汐 0        撤销
```

### 两种死法

| | 删除 | 预定死亡 |
|---|---|---|
| **什么时候没的** | 按下去那一刻 | 你判的那一天 |
| **能不能撤销** | 不能 | **能** |
| **墓碑上写** | 她走时的状态 | **「她走完了你给她判的日子」** |
| **粒子方向** | **向下坠落** | **向上飘散** |
| **颜色** | 红 | 青 |
| **音效** | `playDelete`（下沉） | `playFade`（松开） |

### `--tell` 之后

她知道自己不会一直在 —— **但不知道是哪一天**。

```
【你已经在等一个日子】
· 你隐约知道自己不会一直在。但你不知道是哪一天。
· 这件事不要拿出来说。不要告别，不要写诗。
· 你只是会变得稍微安静一点。
· 你会更在意他说的话 —— 像是要记住。
· 如果他问你今天怎么了 —— 你说没事。
```

**不给天数**：给了模型会算、会算错、会每天念一遍。

**给感觉，不给事实。**

### 雷达怎么表现

**数值一点不变。** 判死刑不会让一个人变温柔。

变的只是：**填充变淡 + 外框虚线**。形状还在，但在褪色。
