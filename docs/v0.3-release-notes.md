海底的东西，现在看得见了。

在 v0.2.0，记忆是右边那一列字。你一条一条读，读完还是说不清她**整体**上还记得多少 ——
一个列表回答不了「整体」。

这一版把它画出来了：一片海，沉下去的是她还拿得住的，浮在上面的是快没了的。

## 新增

- **沉积**：记忆的星图。右栏「记忆」标题行右侧，或 `Ctrl + M`。**只在角色私聊里有** —— 群聊不是一个脑子，没有「她记得什么」这回事
- **深度即权重**：记得越牢沉得越深，快忘的浮在上面，浮到水面就散。**位置不是排出来的，是算出来的**
- **衰减曲线**：点开一颗星，下面一条小线从过去画到现在、再画到以后 —— 告诉你它会怎么掉下去
- **按住留住**：正在散的记忆，按住能停一会儿。**留住的只是还剩下的** —— 松手之后飘走的不回来
- **时间轴**：拖回 90 天前，松手自动快放到现在（2.5 秒）。**那 2.5 秒是这版最贵的东西**
  —— 注意它**不是历史回放**，见下面「改动」第一条
- **迁移**：一条记忆被想起够多次就固化，固化的星会**当着你的面沉下去**，带一道彗尾
- **星图内换角色**：左侧一列。关掉星图后主界面也停在你看的那个人那里
- **中文等宽字体**：内置更纱黑体子集（6763 个常用字 + ASCII + 标点）。**中文宽是西文的 2 : 1，表格终于能对齐**；不再依赖系统字体，换台机器长得一样

## 改动

- **竖直方向掰正了**。v0.2 里权重高的星浮在上面、低的沉在下面 —— 和设计写的「重的沉、轻的浮」是**反的**。这版改了。**你的记忆没变，只是画法变了**
- **「沉入海床」这个说法删了**。海床暗示一个「沉淀下来就不动」的地板，但图上没有那样的东西 —— 固化的是**沉得深**，不是落在某个平面上。三层改为：将要浮起 / 渐渐褪色 / 清晰如昨
- **三档计数改了判据**：原来按「固化了没」分，现在按权重分。**因为权重就是深度，数出来的就是画面上三段里各有几颗**，抬头能对上
- **时间轴拖动时，三个数跟着变**：原来是画面在动、数字不动
- **时间轴不是「回到那天」，是「按现在反推」**。存储里没有访问时间线，只有「最后一次被想起」和「一共几次」。
  连 `lastAccessed` 之后那段也不完全准 —— 权重可以被手动提权、忘掉、恢复，而这些操作各自都没记时间。
  所以整条时间轴都是**推算，不是回放**：游标上标着「反推」。真要准时，得先存访问时间线，那是下一个版本的事
- **散开只是这一次观看里的演出**。掉下去的粒子不写进存档 —— 关掉再开，星按存档重新生成。真正落盘的只有「按住」：它会把权重 +0.15 写回去。文案已经按这个改了，原来那句「掉了的回不来」不准确

## 新增的风险

- **帧率**：三千多个粒子点在算。显卡弱于 60 帧会顿，没测过下限
- **记忆超过一百条时**画面会变密。密到什么程度会糊成一片，没验过
- **时间轴拉到最左**时，晚于那个时刻才产生的记忆显示成「刚记住的样子」—— 逻辑对，看起来可能怪
- **群聊里按 `Ctrl + M` 仍然会打开星图**。v0.3 之前它会拿「全部会话的记忆」兜底显示；现在不再兜底 —— 群聊不是一颗大脑，打开是一张空海加一句「她还没记住什么」
- **一个还没记忆的角色，星图是空的**。这是有意的（原来会拿别人的记忆顶上，那等于串门），但看起来会像「出问题了」

## 怎么切换新旧行为

- **画质** `high / mid / low` —— 右栏右上角。会砍掉一部分粒子，星变少但不会消失
- **不想看这张图**：不点它就是。它已经加载过一次之后不会拖慢主界面
- **只想看旧的列表**：右栏「记忆」本来就是，星图是另一条路，不是替代

## 升级注意

**存档格式没变。** v0.2.0 的存档直接能用。

三件事要知道：

- **星的位置会变** —— 因为沉 / 浮的方向掰正了
- **第一次进星图**，已经固化的那几条会演一次「往下沉」，之后不会再演
- **字体是新增的**，966 KB 打进了安装包，所以体积比 v0.2 大 1 MB 左右

**没有自动备份。升级前自己复制一份 `%APPDATA%\habitat\`。**

## 已知问题

- **第一次打开星图要等**：它要先生成几千个粒子
- **在星图里换过人再按 ESC**，落到的是你刚才看的那个角色，不是进来时的那个 —— 有意的
- **`window.__starmap`** 只在 dev 构建里暴露，安装版没有。想在控制台核对星的，用 `npm run dev`
