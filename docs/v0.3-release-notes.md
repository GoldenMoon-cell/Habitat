深渊里，遗忘有了形状。

在 v0.2.0 里，记忆是右边那一列字。你逐条读下来，却始终拼凑不出她**整体**上还记得多少 ——
一个列表回答不了「整体」。

……而现在，那些字沉进了水里：沉底的，是执念；上浮的，是遗忘。

## 新增

- **沉积**：记忆的星图。按 `Ctrl + M`，或右栏「记忆」页里、标题行右边的 `沉积 ›`。
  五秒下潜之后是一片海底，散着的发光点会自己游到一起，**排成一句话**
- **沉与浮**：记得越牢沉得越深，快忘的浮在上面，浮到水面就散。
  **位置不是排出来的，是算出来的** —— 权重换算成深度，同一个数决定亮度和位置
- **衰减曲线**：点开一颗星，下面浮出它的来历，和一条从过去画到现在、再画到以后的线
- **按住留住它**：正在散的记忆，按住能停一会儿。**留住的只是还未消散的那部分** ——
  松开之后它继续按原来的速度衰减
- **时间轴**：拖回 90 天前，松手自动快放到现在。那 2.5 秒是这一版最费工的东西 ——
  你能看见它们一条一条浮上去、暗下去
- **迁移**：一条记忆被想起够多次就固化，固化的星会**当着你的面沉下去**，带一道彗尾
- **星图内换角色**：进去之后左侧一列名字，点一下换一片星域。关掉星图回到主界面，
  也停在你选中的角色
- **中文等宽字体**：内置更纱黑体子集（6763 个常用字 + ASCII + 标点）。
  **中文宽是西文的 2 : 1，表格终于能对齐**；不再依赖系统字体，换台机器长得一样

## 改动

- **竖直方向掰正了**。v0.2 里权重高的星浮在上面、低的沉在下面，和设计写的
  「重的沉、轻的浮」**是反的**。这一版改了。**你的记忆没变，只是画法变了**
- **「沉入海床」这个说法删了**。海床暗示一个「沉淀下来就不动」的地板，但图上没有那样的东西 ——
  固化的是**沉得深**，不是落在某个平面上
- **三档改成按权重分**，不按「固化了没」分：将要浮起 / 渐渐褪色 / 清晰如昨
- **时间轴不是「回到那天」，是「按现在反推」**。存储里只有「最后一次被想起」和「一共几次」，
  没有访问时间线。游标上标着「反推」——**它算不出某天的真实星图**
- **散开只是这一次观看里的演出**。掉下去的粒子不写进存档，关掉再开按存档重新生成。
  真正落盘的只有「按住」
- **一个还没记忆的角色，星图是空的**。以前会拿「全部会话的记忆」兜底显示，那是串门
- **切走之后不会再回话了**。v0.2 里离开一个会话，它排着的回复还在触发 ——
  群里发一句、立刻切走，几秒后原群冒出一句没人问的话

## 新增的风险

- **显卡性能不足会掉帧**：每条记忆压成 **11000 颗粒子**，另加 18900 颗海雪光斑，
  再跑**三段主要后处理**（泛光 / 镜头 / 颗粒）—— 七条记忆就是九万多颗
- **记忆超过一百条时**画面会变密。密到什么程度会糊成一片，未验证
- **时间轴拉到最左**时，晚于那个时刻才产生的记忆显示成「刚记住的样子」——
  逻辑正确，但视觉上可能会怪
- **真模型的多气泡回复没验过**。演示模式不拆气泡（拆气泡那段只在真模型路径里），
  本地驱动不到
- **群聊里按 `Ctrl + M` 仍然会打开星图**，现在是一张空海加一句
  「这片海域，尚无任何记忆沉积。」

## 怎么切换画面效果

右栏右上角：

- `high`：渲染分辨率 **2 倍**（受显示器像素比限制），泛光 + 镜头 + 颗粒**全开**
- `mid`：**1.5 倍**，保留泛光，关掉镜头和颗粒
- `low`：**1 倍**，并且**关掉泛光**

**改的只是分辨率和后处理，粒子数不变 —— 星不会变少。**

不想看这张图：不点入口按钮即可。只想看列表：右栏「记忆」就是列表样式，
星图是另一个呈现方式，不是替代。

## 升级注意

**存档格式不变。** v0.2.0 的存档可直接使用。

三件事要知道：

- **星的位置会变** —— 因为沉 / 浮的方向掰正了
- **第一次进星图**，已经固化的那几条会演一次「往下沉」，之后不会再演
- **字体是新增的**，966 KB 打进了安装包，所以体积比 v0.2（90 MB）大了约 1 MB（91 MB）

**没有自动备份。升级前自己复制一份 `%APPDATA%\habitat\`。**

## 已知问题

- **第一次打开星图需要等待**：它要先生成几千个粒子
- **在星图里换过人再按 ESC**，落到的是你刚才选中的角色，不是进来时选中的那个 —— 有意的
- **`window.__starmap`** 只在 dev 构建里暴露，装好的这个没有。
  想在控制台核对星图数据，用 `npm run dev`
- 时间轴显示的是基于存档的推算，不能还原每天真实发生过的记忆变化
- 在群聊中打开星图时，显示的是群会话的记忆汇总
